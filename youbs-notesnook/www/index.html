Serveur Notesnook

Ce serveur n'a pas d'interface web : utilisez les apps officielles Notesnook (bureau et mobile) en les pointant vers les adresses ci-dessous.

1. Adresses à saisir dans Notesnook

Avant de vous connecter : écran de connexion > Configurer le serveur (ou Paramètres > Serveurs).

Serveur de synchrohttps://notesnook-sync.home.youbs.fr
Serveur d'authentificationhttps://notesnook-auth.home.youbs.fr
Serveur d'événementshttps://notesnook-events.home.youbs.fr
Serveur Monographhttps://notesnook-monograph.home.youbs.fr

2. Hôtes à créer dans Nginx Proxy Manager

Chaque hôte relaie vers http://192.168.31.144:<port>, avec le certificat wildcard *.home.youbs.fr.

notesnook-authport 8493
notesnook-syncport 8494, cocher Websockets Support
notesnook-eventsport 8495
notesnook-monographport 8496
notesnook-filesport 8497 (pièces jointes)

3. Après l'inscription

Aucun serveur d'e-mails n'est configuré : la double authentification par e-mail ne peut pas fonctionner.
  1. Créez votre compte dans l'app : vous êtes connecté directement.
  2. Tout de suite, allez dans Paramètres > Authentification > Changer de méthode 2FA et choisissez une app d'authentification. Sauvegardez les codes de récupération.
  3. Sans cette étape, la connexion depuis un autre appareil demandera un code par e-mail qui n'arrivera jamais.
  4. Une fois vos comptes créés, bloquez les inscriptions : DISABLE_SIGNUPS: "true" dans le docker-compose, puis redémarrez l'app.
